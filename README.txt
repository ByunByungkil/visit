[포함된 파일]
  index.html              신청 폼 페이지
  calendar.html           공개 예약 캘린더 페이지

  js/config.js            설정 파일 (★ 반드시 수정 필요)

  README.txt              이 안내 파일


====================================================================
STEP 1. 구글 스프레드시트 준비
====================================================================
1. 아래 스프레드시트를 엽니다.
   https://docs.google.com/spreadsheets/d/1p7_GH-pIZtKJ6pVWIIK3FDp5l7oWnbJjkFpzAj8-4VA/edit

2. gid=362671523 탭(또는 새 탭)의 이름을 "신청현황"으로 설정합니다.
   (code.gs의 SHEET_NAME 과 반드시 일치해야 합니다.)

3. [확장 프로그램] > [Apps Script] 를 클릭합니다.

4. 기본 코드를 모두 지우고 첨부된 code.gs 의 내용을 붙여넣습니다.

5. 저장(디스크 아이콘)합니다.


====================================================================
STEP 2. 웹앱 배포 및 URL 설정
====================================================================
1. Apps Script 화면 우측 상단의 [배포] > [새 배포] 클릭

2. 유형: "웹 앱"
   설명: 가을대심방 신청 (또는 자유롭게)
   다음 사용자 권한으로 실행: 본인 계정
   액세스 권한이 있는 사용자: 전체 (익명 사용자 포함)
   ⚠ "액세스 권한이 있는 사용자"를 반드시 "전체"로 설정

3. [배포] 클릭 → 권한 승인

4. 나타난 "웹 앱 URL"을 복사합니다.
   예: https://script.google.com/macros/s/AKfycb.../exec

5. js/config.js 를 열어 GAS_WEB_APP_URL 값을 위에서 복사한 URL로 교체합니다.


====================================================================
STEP 3. 홈페이지 설정 변경
====================================================================
js/config.js 를 열어 아래 값들을 실제 정보로 수정합니다:

  1) GAS_WEB_APP_URL
     → STEP 2 에서 복사한 웹 앱 URL

  2) START_DATE, END_DATE
     → 기본값: 2026-10-19 ~ 2026-10-24
     → 변경 필요 시 YYYY-MM-DD 형식으로 수정

  3) TIME_SLOTS
     → 기본 7개 시간 구간 설정됨
     → 시간 추가/삭제 필요시 수정

추가 수정 사항:
  - index.html: 교회 전화번호 (000-0000-0000)
  - calendar.html: 교회 전화번호


====================================================================
STEP 4. 사이트 호스팅
====================================================================
옵션 1: 로컬에서 테스트
  - index.html 을 브라우저에서 열기
  - 주소 입력 후 신청하면 시트에 저장됨

옵션 2: 웹호스팅 서비스에 업로드
  - 폴더 전체(css/, js/, *.html)를 업로드
  - 교회 홈페이지에 임베드
  - 카페24, Netlify, Github Pages 등 가능


====================================================================
동작 흐름
====================================================================
1. 사용자가 index.html 에서 성명/주소/날짜/시간 입력 후 신청
2. Apps Script 가 데이터를 구글 시트에 저장
3. 신청이 완료되면 "신청이 완료되었습니다" 메시지 표시
4. calendar.html 은 실시간으로 예약 현황 표시 (30초마다 자동 갱신)
5. 선착순으로 선택된 날짜/시간은 신청 페이지에서 disabled 표시


====================================================================
FAQ
====================================================================
Q: 신청 후 시트에 데이터가 안 보인다?
A: 1) GAS_WEB_APP_URL 설정 확인
   2) code.gs 의 SHEET_NAME 이 "신청현황"인지 확인
   3) Apps Script 가 최신 버전으로 배포되었는지 확인
      ([배포 관리] > 새 버전으로 재배포)

Q: 예약 캘린더가 비어있다?
A: 1) 신청 페이지에서 먼저 테스트 신청해보기
   2) 새로고침 버튼을 누르거나 페이지 새로고침
   3) GAS_WEB_APP_URL 이 올바른지 확인

Q: 시간 구간을 추가/삭제하려면?
A: js/config.js 의 TIME_SLOTS 배열 수정
   예: slot_7, slot_8 등 추가 가능
   (slot ID는 겹치지 않아야 함)

Q: 시트에 저장된 시간 정보가 이상하다?
A: code.gs 의 "2026-10-19|slot_0" 형식이 맞는지 확인
   calendar.html 에서 보이는 형식과 일치해야 합니다.
